# TURN / Rubik's Cube V2

Réimplémentation indépendante de V1, avec une interface et un moteur de cubies 3D distincts.

Fonctions :

- formats 2×2, 3×3, 3×3 twisted et 4×4 ;
- caméra contrôlable par glisser-déposer ;
- mouvements U/D/L/R/F/B, variantes prime et double ;
- séquences de notation ;
- animation des cubies de la couche active ;
- vitesse réglable, mélange de 20 tours, compteur et journal.

Ouvrir `index.html` directement dans un navigateur.
